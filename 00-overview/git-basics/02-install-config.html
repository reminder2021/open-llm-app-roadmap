安装 Git

Windows 用户

  1. 访问 git-scm.com/downloads
  2. 点击 "Download for Windows"
  3. 双击下载的安装包
  4. 一路点击 "Next" 使用默认设置即可
  5. 安装完成后，右键桌面，应该能看到 "Git Bash Here" 选项

Mac 用户

Mac 通常自带 Git，打开终端输入以下命令检查：

git --version

如果显示版本号（如 git version 2.39.0），说明已经安装了。

如果没有安装，会提示你安装 Xcode Command Line Tools，按提示安装即可。

也可以用 Homebrew 安装（Mac）

# 安装 Homebrew（如果没有的话）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 Git
brew install git

基本配置

安装完成后，需要配置你的用户名和邮箱。这些信息会记录在每次提交中。

重要：请把下面的 "你的名字" 和 "你的邮箱" 替换成你自己的信息。 
# 配置用户名（建议用 GitHub 用户名）
git config --global user.name "你的名字"

# 配置邮箱（建议用 GitHub 注册邮箱）
git config --global user.email "你的邮箱@example.com"

示例

# 示例（请替换成你自己的信息）
git config --global user.name "zhangsan"
git config --global user.email "zhangsan@example.com"

查看配置

# 查看所有配置
git config --list

# 查看特定配置
git config user.name
git config user.email
💡 小贴士：--global 表示全局配置，对所有仓库生效。只需要配置一次。

验证安装

运行以下命令，确认 Git 已经正确安装和配置：

# 检查 Git 版本
git --version
# 输出类似: git version 2.39.0

# 检查用户名
git config user.name
# 输出: 你配置的用户名

# 检查邮箱
git config user.email
# 输出: 你配置的邮箱
如果所有命令都能正常输出，恭喜你！Git 已经配置好了。
