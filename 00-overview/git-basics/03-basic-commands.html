克隆仓库（git clone）

从 GitHub 下载一个仓库到本地。

示例：克隆远程仓库
# 语法：git clone <仓库地址>
git clone https://github.com/用户名/仓库名.git

# 示例：克隆本学习路线仓库
git clone https://github.com/用户名/open-llm-app-roadmap.git

# 克隆完成后，进入仓库目录
cd open-llm-app-roadmap

# 查看仓库内容
ls
💡 小贴士：
  • 仓库地址可以在 GitHub 仓库页面点击 "Code" 按钮复制
  • 克隆会自动创建一个文件夹，名字就是仓库名
  • 克隆只需要做一次，之后用 pull 更新即可

初始化仓库（git init）

把一个普通文件夹变成 Git 仓库。

示例：初始化新仓库
# 创建一个新文件夹
mkdir my-project
cd my-project

# 初始化 Git 仓库
git init

# 查看是否初始化成功
ls -la
# 会看到一个 .git 隐藏目录
什么时候用 clone，什么时候用 init？
  • git clone：从 GitHub 下载已有仓库
  • git init：创建全新仓库（之后需要关联远程仓库）

添加和提交（git add + git commit）

修改代码后，需要先添加到暂存区，再提交到本地仓库。

示例：修改文件并提交
# 1. 创建或修改文件
echo "# 我的第一个项目" > README.md

# 2. 查看当前状态（会显示有未跟踪的文件）
git status

# 3. 添加文件到暂存区
git add README.md

# 4. 提交到本地仓库
git commit -m "添加 README 文件"

# 5. 再次查看状态（会显示没有待提交的更改）
git status
示例：添加所有文件
# 添加所有修改的文件
git add .

# 或者添加所有文件
git add -A

# 提交
git commit -m "提交说明"
⚠️ 注意：
  • 每次提交都要写说明（-m "说明"），说明这次改了什么
  • 说明要简洁明了，比如 "修复登录bug"、"添加用户功能"
  • 不要写 "update"、"修改" 这样没有信息量的说明

推送到远程（git push）

把本地的提交推送到 GitHub。

示例：推送到 GitHub
# 首次推送（设置上游分支）
git push -u origin main

# 之后的推送
git push
分支名称说明：
  • 以前默认分支叫 master
  • 现在 GitHub 默认分支叫 main
  • 你可以用 git branch 查看当前分支名
💡 小贴士：
  • 推送前先 pull，避免冲突
  • 如果提示需要登录，按提示操作即可
  • 第一次推送可能需要配置 GitHub 认证

拉取更新（git pull）

从 GitHub 拉取最新的代码到本地。

示例：拉取远程更新
# 拉取远程仓库的更新
git pull

# 如果有冲突，需要手动解决后提交
什么时候需要 pull？
  • 开始工作前，先 pull 确保代码是最新的
  • 别人推送了新代码，你需要 pull 获取
  • 在不同电脑上工作，需要同步代码

查看状态和日志

随时了解仓库的状态和历史。

示例：查看状态
# 查看当前状态
git status

# 输出说明：
# On branch main        - 当前在 main 分支
# nothing to commit     - 没有待提交的更改
# working tree clean    - 工作区干净
示例：查看提交历史
# 查看提交历史
git log

# 简洁模式
git log --oneline

# 图形模式（推荐）
git log --graph --oneline
完整工作流程示例
# 1. 拉取最新代码
git pull

# 2. 修改文件（用编辑器修改）
# ... 编辑代码 ...

# 3. 查看修改了哪些文件
git status

# 4. 添加修改的文件
git add .

# 5. 提交
git commit -m "完成用户登录功能"

# 6. 推送到 GitHub
git push

常用命令速查表

# 下载仓库
git clone <仓库地址>

# 初始化新仓库
git init

# 查看状态
git status

# 添加文件
git add <文件名>      # 添加单个文件
git add .             # 添加所有文件

# 提交
git commit -m "说明"

# 推送
git push

# 拉取
git pull

# 查看历史
git log
git log --oneline
