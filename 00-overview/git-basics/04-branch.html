第四章：分支管理

分支是 Git 最强大的功能之一，让你可以同时开发多个功能，互不影响。

建议时长：30 分钟 目标：会创建和切换分支

什么是分支？

分支就像是代码的"平行宇宙"，你可以在不同的分支上做不同的事情，互不影响。

通俗理解

想象你在写论文：

  • 主分支（main）：论文的正式版本
  • 新分支：你想尝试一种新的写法，但不想影响正式版本
  • 你可以在新分支上随便改，改好了再合并到主分支

主分支（main）

存放稳定的、可发布的代码。

开发分支（dev）

存放正在开发的代码。

功能分支（feature）

开发某个具体功能。

修复分支（fix）

修复某个 bug。

基本操作

查看分支
# 查看所有分支
git branch

# 输出说明：
# * main      - 当前分支（前面有 * 号）
#   dev       - 其他分支
创建新分支
# 创建新分支
git branch new-feature

# 创建并切换到新分支（推荐）
git checkout -b new-feature

# 或者用 switch（更新的命令）
git switch -c new-feature
切换分支
# 切换到指定分支
git checkout main

# 切换到 dev 分支
git checkout dev

# 或者用 switch
git switch main
删除分支
# 删除已合并的分支
git branch -d branch-name

# 强制删除（即使没有合并）
git branch -D branch-name

合并分支

把一个分支的修改合并到另一个分支。

合并分支
# 1. 切换到目标分支（比如 main）
git checkout main

# 2. 合并其他分支
git merge new-feature

# 3. 合并完成后，可以删除分支
git branch -d new-feature
完整流程示例
# 1. 从 main 分支创建新分支
git checkout -b feature-login

# 2. 在新分支上开发（修改代码）
# ... 编辑代码 ...

# 3. 提交修改
git add .
git commit -m "完成登录功能"

# 4. 切换回 main 分支
git checkout main

# 5. 合并功能分支
git merge feature-login

# 6. 推送到 GitHub
git push

# 7. 删除功能分支
git branch -d feature-login
💡 小贴士：
  • 每个功能一个分支，保持分支独立
  • 分支名要有意义，比如 feature-login、fix-bug-123
  • 开发完成后及时合并和删除分支
