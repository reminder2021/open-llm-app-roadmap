第五章：GitHub 使用

GitHub 是全球最大的代码托管平台，学会使用 GitHub 是开发者的必备技能。

建议时长：1 小时 目标：会在 GitHub 上创建和管理仓库

本章内容

注册账号 创建仓库 关联本地仓库 协作开发 ← 上一章：分支管理 返回主页 →

注册 GitHub 账号

  1. 访问 github.com
  2. 点击 "Sign up" 按钮
  3. 输入邮箱、密码、用户名
  4. 完成验证
  5. 登录你的邮箱，点击验证链接

创建仓库

在 GitHub 上创建一个新的代码仓库。

步骤

  1. 登录 GitHub
  2. 点击右上角的 "+" 图标，选择 "New repository"
  3. 填写仓库信息：
    • Repository name：仓库名称，比如 my-project
    • Description：仓库描述（可选）
    • Public/Private：公开或私有
    • Initialize this repository with a README：是否创建 README 文件
  4. 点击 "Create repository" 按钮
💡 小贴士：
  • 如果是学习项目，建议选 Public（公开）
  • 勾选 "Add a README file" 可以直接克隆

关联本地仓库

把本地的 Git 仓库和 GitHub 上的仓库关联起来。

方式一：从零开始
# 1. 在 GitHub 上创建仓库（不要勾选 README）

# 2. 在本地初始化仓库
git init

# 3. 添加文件并提交
git add .
git commit -m "初始提交"

# 4. 关联远程仓库（把地址换成你自己的）
git remote add origin https://github.com/用户名/仓库名.git

# 5. 推送到 GitHub
git push -u origin main
方式二：克隆已有仓库
# 1. 在 GitHub 上创建仓库（勾选 README）

# 2. 克隆到本地
git clone https://github.com/用户名/仓库名.git

# 3. 进入仓库目录
cd 仓库名

# 4. 修改代码后提交
git add .
git commit -m "修改说明"

# 5. 推送
git push
方式三：关联已有仓库
# 1. 在本地已有 Git 仓库

# 2. 在 GitHub 上创建仓库（不要勾选 README）

# 3. 关联远程仓库
git remote add origin https://github.com/用户名/仓库名.git

# 4. 推送
git push -u origin main

协作开发

和团队成员一起开发同一个项目。

Fork 和 Pull Request

  1. Fork：复制一份别人的仓库到自己的账号下
  2. Clone：把 Fork 的仓库克隆到本地
  3. 修改：在本地修改代码
  4. Push：推送到自己的仓库
  5. Pull Request：请求原仓库的作者合并你的修改
示例：参与开源项目
# 1. Fork 项目（在 GitHub 网页上操作）

# 2. 克隆你 Fork 的仓库
git clone https://github.com/你的用户名/仓库名.git

# 3. 创建新分支
git checkout -b my-feature

# 4. 修改代码
# ... 编辑代码 ...

# 5. 提交
git add .
git commit -m "添加新功能"

# 6. 推送到你的仓库
git push origin my-feature

# 7. 在 GitHub 上创建 Pull Request
💡 小贴士：
  • Fork 后，你的仓库和原仓库是独立的
  • 如果原仓库更新了，你需要手动同步
  • Pull Request 是开源协作的核心机制

常用 GitHub 功能

Issues

记录任务、bug、功能请求。

Pull Requests

提交代码变更，请求合并。

Actions

自动化工作流，比如自动测试、部署。

Pages

免费托管静态网站。
