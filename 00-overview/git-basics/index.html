Git 入门

Git 是开发者必备的工具，用来管理代码版本、协作开发。这个模块用最简单的方式教你学会 Git 的基本操作。

建议时长：1-2 天 目标：会用 Git 管理自己的代码 前置要求：会用命令行

章节导航

学习指引 01 Git 是什么 02 安装和配置 03 基本操作 04 分支管理 05 GitHub 使用 返回 00 总览

为什么需要学 Git？

版本管理

代码改坏了可以回退，不用担心丢失之前的版本。

协作开发

多人同时修改代码，不会互相覆盖。

代码备份

代码存在 GitHub 上，电脑坏了也不怕。

提交作业

在本学习路线中，你需要用 Git 提交学习成果。

这个模块适合谁？

✅ 适合你

  • 从来没用过 Git
  • 听说过但不会用
  • 只会用 GitHub 网页上传文件

⏭️ 可以跳过

  • 已经会用 git add/commit/push
  • 熟悉分支操作
  • 用过 GitHub/GitLab 协作

学习路径

第 1 天：理解 + 安装 + 配置

理解 Git 的概念，安装 Git，配置基本信息。

第 2 天：基本操作 + GitHub

学会 clone、add、commit、push、pull，以及使用 GitHub。

常用命令速查

先有个印象，后面会详细讲解：

git clone <仓库地址>     # 下载远程仓库
git add <文件>           # 添加文件到暂存区
git commit -m "说明"     # 提交更改
git push                 # 推送到远程仓库
git pull                 # 从远程仓库拉取更新
git status               # 查看当前状态
git log                  # 查看提交历史
