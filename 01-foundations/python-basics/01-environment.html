第一章：环境搭建

在写代码之前，先准备好开发环境。这章会教你安装 Python、配置编辑器、学会用命令行运行代码。

建议时长：1-2 天 目标：能用命令行运行一个 Python 文件

本章内容

为什么需要环境 安装 Python 安装编辑器 认识命令行 第一个程序 交互模式 练习 下一章：基本语法 →

为什么需要搭建环境？

Python 代码需要在 Python 解释器上运行。就像你需要一个播放器才能播放音乐一样，你需要安装 Python 才能运行 Python 代码。

你需要准备

  • Python 解释器（运行代码的工具）
  • 代码编辑器（写代码的地方）
  • 命令行终端（执行代码的地方）

你不需要

  • 复杂的 IDE（初期用轻量编辑器即可）
  • 高级配置（后面会慢慢学）
  • 多个 Python 版本（一个就够了）

第一步：安装 Python

Python 是免费开源的编程语言，安装很简单。

Windows 用户

  1. 打开浏览器，访问 python.org/downloads
  2. 点击黄色的 "Download Python 3.x.x" 按钮
  3. 下载完成后，双击运行安装程序
  4. 重要：勾选 "Add Python to PATH"（把 Python 添加到环境变量）
  5. 点击 "Install Now" 开始安装
  6. 等待安装完成

Mac 用户

  1. 打开"终端"应用（在 应用程序 → 实用工具 里）
  2. 输入以下命令检查是否已安装 Python：
python3 --version

如果显示 "Python 3.x.x"，说明已经安装了。如果没有，会提示你安装 Xcode Command Line Tools，按提示安装即可。

验证安装：安装完成后，打开命令行（Windows 的 CMD 或 PowerShell，Mac 的终端），输入： 
python3 --version
应该看到类似 "Python 3.11.0" 的输出。

第二步：安装代码编辑器

虽然可以用记事本写代码，但专业的编辑器会帮你高亮语法、自动补全、运行代码，强烈推荐 VS Code。

安装 VS Code

  1. 访问 code.visualstudio.com
  2. 下载对应你操作系统的版本
  3. 安装完成后打开 VS Code

安装 Python 插件

  1. 在 VS Code 左侧点击"扩展"图标（四个方块的图标）
  2. 搜索 "Python"
  3. 安装由 Microsoft 发布的 "Python" 插件
  4. 安装完成后，VS Code 就能识别 Python 代码了
为什么要用 VS Code？
  • 免费开源
  • 支持 Python 语法高亮和自动补全
  • 内置终端，可以直接运行代码
  • 插件丰富，后续做 LLM 开发也很方便

第三步：认识命令行

命令行是用文字输入命令的地方，看起来有点"原始"，但它是最基础、最强大的工具。

打开命令行

  • Windows：按 Win 键，输入 "cmd" 或 "PowerShell"，打开
  • Mac：打开"终端"应用（在 应用程序 → 实用工具 里）

常用命令

查看当前位置

pwd

pwd = Print Working Directory，显示你当前在哪个文件夹

列出文件

# Windows
dir

# Mac/Linux
ls

列出当前文件夹里的所有文件和文件夹

进入文件夹

# 进入名为 my_project 的文件夹
cd my_project

# 返回上一级文件夹
cd ..

# 进入桌面（Mac）
cd ~/Desktop

cd = Change Directory，切换到指定文件夹

创建文件夹

# Windows
mkdir my_project

# Mac/Linux
mkdir my_project

mkdir = Make Directory，创建新文件夹

小技巧：在 VS Code 中，你可以用快捷键 `Ctrl + ~`（Windows）或 `Cmd + ~`（Mac）打开内置终端，不用切换窗口。

第四步：写第一个程序

现在让我们写一个最简单的 Python 程序。

步骤 1：创建文件

  1. 打开 VS Code
  2. 点击"文件" → "新建文件"
  3. 点击"文件" → "另存为"
  4. 选择一个位置（比如桌面），文件名输入 hello.py

步骤 2：写代码

在编辑器中输入以下代码：

print("你好，世界！")
print("我开始学 Python 了！")

步骤 3：运行代码

有两种方式运行：

方式一：在 VS Code 中运行

  1. 打开 hello.py 文件
  2. 点击右上角的 ▶️ 按钮
  3. 下方终端会显示输出

方式二：在命令行中运行

  1. 打开命令行
  2. 用 cd 进入文件所在文件夹
  3. 输入 python3 hello.py
你应该看到： 
你好，世界！
我开始学 Python 了！
如果看到了，恭喜你！你已经成功运行了第一个 Python 程序！

第五步：交互模式

除了写文件运行，Python 还有一个"交互模式"，可以一行一行地执行代码，适合快速测试。

进入交互模式

在命令行输入 python3（不带文件名），会看到类似这样的提示符：

Python 3.11.0 (main, Oct 24 2022, 18:26:48)
>>>

>>> 就是 Python 交互模式的提示符，表示你可以输入 Python 代码了。

试试这些

>>> 1 + 1
2

>>> print("你好")
你好

>>> name = "小明"
>>> print(f"你好，{name}！")
你好，小明！

>>> exit()

输入 exit() 可以退出交互模式。

交互模式的用途：
  • 快速测试一行代码
  • 学习新语法
  • 调试小问题

练习

完成以下练习，确保你已经掌握了环境搭建：

练习 1：验证 Python 安装

打开命令行，输入以下命令，确认能看到版本号：

python3 --version

练习 2：创建并运行文件

创建一个文件 my_name.py，写入以下代码并运行：

print("我的名字是：______")  # 把 ______ 换成你的名字
print("我正在学习 Python！")

练习 3：使用交互模式

进入 Python 交互模式，试试这些计算：

>>> 10 + 20
>>> 100 - 50
>>> 5 * 8
>>> 10 / 3
>>> 2 ** 10  # 2 的 10 次方

练习 4：命令行操作

用命令行完成以下操作：

  1. 在桌面创建一个文件夹 python_learning
  2. 进入这个文件夹
  3. 创建一个文件 hello.py 并在里面写 print("Hello!")
  4. 用命令行运行这个文件
