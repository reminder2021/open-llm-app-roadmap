变量

变量是用来存储数据的"盒子"。你可以把数据放进去，之后用变量名来使用它。

创建变量

# 用 = 号给变量赋值
name = "小明"
age = 25
height = 1.75
is_student = True

# 打印变量的值
print(name)      # 输出: 小明
print(age)       # 输出: 25
print(height)    # 输出: 1.75
print(is_student) # 输出: True

变量命名规则

  • 只能包含字母、数字和下划线 _
  • 不能以数字开头
  • 区分大小写：name 和 Name 是不同的变量
  • 建议用有意义的名字：user_name 比 x 好

合法和非法的变量名

# ✅ 合法的变量名
user_name = "小明"
age_25 = 25
_private = "私有"

# ❌ 非法的变量名（会报错）
# 2name = "小明"      # 数字开头
# my-name = "小明"    # 包含连字符
# class = "Python"    # 使用了保留字

修改变量

score = 80
print(score)  # 输出: 80

score = 90    # 修改变量的值
print(score)  # 输出: 90
与 LLM 应用的关联：在 LLM 应用中，你会用变量存储模型返回的结果、用户的输入、API 的响应等。 
user_input = "什么是 RAG？"
model_response = "RAG 是检索增强生成的缩写..."

数据类型

Python 中的数据有不同的类型，最常见的有四种：

字符串 (str)

文本数据，用引号包围

name = "小明"
message = '你好'
multi_line = """这是
多行
文本"""

整数 (int)

没有小数点的数字

age = 25
count = 0
negative = -10

浮点数 (float)

有小数点的数字

height = 1.75
price = 9.99
pi = 3.14159

布尔值 (bool)

只有 True 或 False

is_student = True
has_passed = False

检查数据类型

print(type(name))        # <class 'str'>
print(type(age))         # <class 'int'>
print(type(height))      # <class 'float'>
print(type(is_student))  # <class 'bool'>

类型转换

# 字符串转整数
age_str = "25"
age_int = int(age_str)
print(age_int + 5)  # 输出: 30

# 整数转字符串
score = 85
score_str = str(score)
print("分数是：" + score_str)  # 输出: 分数是：85

# 字符串转浮点数
price_str = "9.99"
price_float = float(price_str)
print(price_float * 2)  # 输出: 19.98
与 LLM 应用的关联：LLM 返回的数据通常是字符串，你需要根据情况转换类型。 
# LLM 返回的可能是字符串 "85"
model_output = "85"

# 需要转换成数字才能计算
score = int(model_output)
if score >= 60:
    print("及格了")

字符串操作

字符串是 LLM 应用中最常用的数据类型，因为模型输入输出都是文本。

字符串拼接

# 用 + 号拼接
first_name = "张"
last_name = "三"
full_name = first_name + last_name
print(full_name)  # 输出: 张三

# 用 f-string 格式化（推荐）
age = 25
message = f"我今年 {age} 岁"
print(message)  # 输出: 我今年 25 岁

# f-string 可以放表达式
price = 9.99
quantity = 3
total = f"总价: {price * quantity} 元"
print(total)  # 输出: 总价: 29.97 元

字符串方法

text = "  Hello, World!  "

# 去掉首尾空格
print(text.strip())  # 输出: Hello, World!

# 转换大小写
print(text.upper())  # 输出:   HELLO, WORLD!  
print(text.lower())  # 输出:   hello, world!  

# 替换
print(text.replace("World", "Python"))  # 输出:   Hello, Python!  

# 查找
print(text.find("World"))  # 输出: 9（位置）

# 切割
print(text.split(","))  # 输出: ['  Hello', ' World!  ']

字符串切片

text = "Hello, World!"

# 获取单个字符
print(text[0])   # 输出: H
print(text[7])   # 输出: W

# 获取子串
print(text[0:5])   # 输出: Hello
print(text[7:12])  # 输出: World

# 从开头或结尾
print(text[:5])    # 输出: Hello
print(text[7:])    # 输出: World!

# 负数索引（从末尾开始）
print(text[-1])    # 输出: !
print(text[-6:])   # 输出:orld!
与 LLM 应用的关联：构造 Prompt 模板时，你会大量使用 f-string 和字符串操作。 
user_question = "什么是 RAG？"
system_prompt = "你是一个专业的 AI 助手。"
full_prompt = f"{system_prompt}\n\n用户问题：{user_question}"

条件判断

让程序根据不同情况执行不同的代码。

if 语句

score = 85

if score >= 60:
    print("及格了")
    print("恭喜！")

if-else 语句

score = 45

if score >= 60:
    print("及格了")
else:
    print("不及格，继续努力")

if-elif-else 语句

score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")

比较运算符

常用比较

a = 10
b = 20

print(a == b)   # False，等于
print(a != b)   # True，不等于
print(a > b)    # False，大于
print(a < b)    # True，小于
print(a >= 10)  # True，大于等于
print(a <= 5)   # False，小于等于

逻辑运算符

age = 25
has_id = True

# and：两个条件都满足
if age >= 18 and has_id:
    print("可以进入")

# or：至少一个条件满足
if age < 12 or age > 60:
    print("免费")

# not：取反
if not has_id:
    print("请出示身份证")
与 LLM 应用的关联：你会用条件判断来处理模型的输出。 
response = "根据资料无法判断"

if "无法判断" in response:
    print("模型表示不知道答案")
elif "根据" in response:
    print("模型给出了有依据的回答")
else:
    print("模型直接回答了")

循环

让程序重复执行某段代码。

for 循环

# 遍历列表
fruits = ["苹果", "香蕉", "橙子"]
for fruit in fruits:
    print(f"我喜欢{fruit}")

# 使用 range 生成数字序列
for i in range(5):
    print(i)  # 输出: 0, 1, 2, 3, 4

# 带索引的遍历
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")

while 循环

# 当条件为 True 时重复执行
count = 0
while count < 5:
    print(count)
    count += 1  # 等同于 count = count + 1

# 注意：一定要有退出条件，否则会无限循环

break 和 continue

# break：提前退出循环
for i in range(10):
    if i == 5:
        break  # 当 i 等于 5 时退出循环
    print(i)   # 输出: 0, 1, 2, 3, 4

# continue：跳过本次循环
for i in range(5):
    if i == 2:
        continue  # 跳过 i 等于 2 的情况
    print(i)      # 输出: 0, 1, 3, 4

实用示例

# 统计列表中及格的人数
scores = [85, 45, 92, 58, 76, 63, 91]
pass_count = 0

for score in scores:
    if score >= 60:
        pass_count += 1

print(f"及格人数: {pass_count}")  # 输出: 及格人数: 5

# 批量处理数据
names = ["张三", "李四", "王五"]
for name in names:
    greeting = f"你好，{name}！欢迎使用 LLM 应用。"
    print(greeting)
与 LLM 应用的关联：循环在 LLM 应用中非常常用，比如批量处理用户输入、遍历测试数据、重试请求等。 
# 重试机制示例
max_retries = 3
for attempt in range(max_retries):
    try:
        # 调用模型 API
        response = call_llm("什么是 RAG？")
        print(response)
        break  # 成功了就退出循环
    except Exception as e:
        print(f"第 {attempt + 1} 次尝试失败: {e}")
        if attempt == max_retries - 1:
            print("重试次数用完，放弃")
