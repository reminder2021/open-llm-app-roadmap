什么是函数？

函数是一段有名字的代码块，可以接收输入、执行操作、返回结果。就像一个"黑盒子"：

输入 → 函数 → 输出

为什么要用函数？

代码复用

写一次，到处使用，避免重复代码。

逻辑清晰

给代码块起名字，更容易理解程序逻辑。

易于维护

修改逻辑只需要改一个地方。

方便测试

可以单独测试每个函数的功能。

定义函数

用 def 关键字定义函数：

基本语法

def 函数名(参数):
    """函数文档（可选）"""
    函数体
    return 返回值  # 可选

最简单的函数

# 定义一个打招呼的函数
def say_hello():
    print("你好！")

# 调用函数
say_hello()  # 输出: 你好！
say_hello()  # 输出: 你好！（可以多次调用）

带参数的函数

# 定义一个打招呼的函数，接收名字参数
def greet(name):
    print(f"你好，{name}！")

# 调用函数
greet("小明")  # 输出: 你好，小明！
greet("李四")  # 输出: 你好，李四！

函数命名规范

  • 使用小写字母和下划线：greet_user、calculate_score
  • 名字要有意义：process_data 比 func1 好
  • 动词开头更清晰：get_name、is_valid、calculate_sum

参数

参数是函数的输入，可以有多个，也可以有默认值。

多个参数

# 两个参数
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 输出: 8

# 三个参数
def introduce(name, age, city):
    print(f"我是{name}，{age}岁，来自{city}")

introduce("小明", 25, "北京")  # 输出: 我是小明，25岁，来自北京

默认参数

# 有默认值的参数
def greet(name, greeting="你好"):
    print(f"{greeting}，{name}！")

greet("小明")              # 输出: 你好，小明！
greet("小明", "早上好")    # 输出: 早上好，小明！
greet("小明", greeting="晚上好")  # 输出: 晚上好，小明！

关键字参数

def create_user(name, age, city="北京"):
    return {"name": name, "age": age, "city": city}

# 位置参数
user1 = create_user("小明", 25)

# 关键字参数（顺序可以不同）
user2 = create_user(age=30, name="李四", city="上海")

print(user1)  # 输出: {'name': '小明', 'age': 25, 'city': '北京'}
print(user2)  # 输出: {'name': '李四', 'age': 30, 'city': '上海'}

可变参数

# *args：接收任意数量的位置参数
def sum_all(*args):
    return sum(args)

print(sum_all(1, 2, 3))       # 输出: 6
print(sum_all(1, 2, 3, 4, 5)) # 输出: 15

# **kwargs：接收任意数量的关键字参数
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="小明", age=25, city="北京")
# 输出:
# name: 小明
# age: 25
# city: 北京

返回值

函数可以用 return 返回结果给调用者。

返回单个值

def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 输出: 8

返回多个值

def get_stats(numbers):
    """返回平均值、最大值、最小值"""
    avg = sum(numbers) / len(numbers)
    return avg, max(numbers), min(numbers)

# 接收多个返回值
average, maximum, minimum = get_stats([85, 92, 78, 91, 73])
print(f"平均: {average}, 最大: {maximum}, 最小: {minimum}")
# 输出: 平均: 83.8, 最大: 92, 最小: 73

返回字典

def create_user(name, age, skills):
    return {
        "name": name,
        "age": age,
        "skills": skills,
        "is_active": True
    }

user = create_user("小明", 25, ["Python", "LLM"])
print(user)
# 输出: {'name': '小明', 'age': 25, 'skills': ['Python', 'LLM'], 'is_active': True}

没有返回值

def print_report(title, content):
    """只是打印，不返回任何值"""
    print(f"=== {title} ===")
    print(content)
    print("=============")

# 函数没有 return 语句时，默认返回 None
result = print_report("测试报告", "所有测试通过")
print(result)  # 输出: None

提前返回

def divide(a, b):
    """安全的除法"""
    if b == 0:
        return None  # 提前返回，避免除零错误
    return a / b

result = divide(10, 0)
print(result)  # 输出: None

result = divide(10, 3)
print(result)  # 输出: 3.3333333333333335

作用域

变量有"作用域"，决定了在哪里可以访问这个变量。

局部变量

def my_function():
    x = 10  # 局部变量，只在函数内部有效
    print(f"函数内部: x = {x}")

my_function()  # 输出: 函数内部: x = 10

# 在函数外部访问 x 会报错
# print(x)  # NameError: name 'x' is not defined

全局变量

x = 10  # 全局变量，在整个文件中有效

def my_function():
    print(f"函数内部: x = {x}")  # 可以读取全局变量

my_function()  # 输出: 函数内部: x = 10
print(f"函数外部: x = {x}")  # 输出: 函数外部: x = 10

修改全局变量

count = 0

def increment():
    global count  # 声明要使用全局变量
    count += 1

increment()
increment()
print(count)  # 输出: 2
建议：尽量避免使用 global 关键字。更好的做法是通过参数传入、返回值传出。

函数文档

用三引号 """ 写函数文档，说明函数的用途、参数和返回值。

基本格式

def calculate_average(numbers):
    """计算数字列表的平均值
    
    Args:
        numbers: 数字列表
    
    Returns:
        平均值，如果列表为空返回 0
    """
    if not numbers:
        return 0
    return sum(numbers) / len(numbers)

查看函数文档

print(calculate_average.__doc__)

# 或者用 help()
help(calculate_average)

完整的函数示例

def extract_keywords(text, max_keywords=5):
    """从文本中提取关键词
    
    Args:
        text: 输入文本
        max_keywords: 最大关键词数量，默认为 5
    
    Returns:
        关键词列表
    
    Raises:
        ValueError: 如果文本为空
    """
    if not text.strip():
        raise ValueError("文本不能为空")
    
    # 简单的关键词提取：按空格分割，去重
    words = text.split()
    unique_words = list(dict.fromkeys(words))
    
    return unique_words[:max_keywords]
