什么是错误？

程序运行时可能会遇到各种问题，比如文件不存在、网络连接失败、数据格式错误等。这些问题会导致程序"崩溃"（停止运行）。

错误示例

# 这些代码会报错
print(1 / 0)  # ZeroDivisionError: division by zero

int("hello")  # ValueError: invalid literal for int()

print(undefined_variable)  # NameError: name 'undefined_variable' is not defined

my_list = [1, 2, 3]
print(my_list[10])  # IndexError: list index out of range

为什么要处理错误？

程序不会崩溃

即使遇到错误，程序也能继续运行。

用户体验更好

给用户友好的提示，而不是一堆错误信息。

方便调试

记录错误信息，方便排查问题。

LLM 应用必备

模型调用可能失败，必须有错误处理。

try/except

用 try/except 捕获和处理异常。

基本语法

try:
    # 可能出错的代码
    result = 1 / 0
except:
    # 出错时执行的代码
    print("发生了错误")

捕获特定类型的错误

# 捕获除零错误
try:
    result = 1 / 0
except ZeroDivisionError:
    print("不能除以零")

# 捕获类型错误
try:
    result = int("hello")
except ValueError:
    print("无法转换成数字")

# 捕获多种错误
try:
    # 可能出错的代码
    pass
except (ValueError, TypeError) as e:
    print(f"发生了错误: {e}")

获取错误信息

try:
    result = int("hello")
except ValueError as e:
    print(f"错误类型: {type(e).__name__}")
    print(f"错误信息: {e}")
    # 输出:
    # 错误类型: ValueError
    # 错误信息: invalid literal for int() with base 10: 'hello'

else 子句

try:
    result = 10 / 2
except ZeroDivisionError:
    print("除零错误")
else:
    # 没有错误时执行
    print(f"计算成功: {result}")
# 输出: 计算成功: 5.0

常见错误类型

了解常见的错误类型，能帮你更快地定位问题。

ValueError

值不正确

try:
    number = int("abc")
except ValueError as e:
    print(f"值错误: {e}")
    # 输出: 值错误: invalid literal for int()

TypeError

类型不匹配

try:
    result = "hello" + 123
except TypeError as e:
    print(f"类型错误: {e}")
    # 输出: 类型错误: can only concatenate str to str

KeyError

字典键不存在

try:
    data = {"name": "小明"}
    print(data["age"])
except KeyError as e:
    print(f"键错误: {e}")
    # 输出: 键错误: 'age'

IndexError

列表索引超出范围

try:
    my_list = [1, 2, 3]
    print(my_list[10])
except IndexError as e:
    print(f"索引错误: {e}")
    # 输出: 索引错误: list index out of range

FileNotFoundError

文件不存在

try:
    with open("nonexistent.txt", "r") as f:
        content = f.read()
except FileNotFoundError as e:
    print(f"文件不存在: {e}")

JSONDecodeError

JSON 格式错误

import json

try:
    data = json.loads("{invalid json}")
except json.JSONDecodeError as e:
    print(f"JSON 解析错误: {e}")

finally

finally 子句无论是否发生错误都会执行，通常用于清理资源。

基本用法

try:
    # 可能出错的代码
    result = 1 / 0
except ZeroDivisionError:
    print("发生了错误")
finally:
    # 无论是否出错都会执行
    print("清理工作完成")

文件操作中的使用

# 读取文件，确保文件被关闭
try:
    f = open("data.txt", "r")
    content = f.read()
    print(content)
except FileNotFoundError:
    print("文件不存在")
finally:
    # 确保文件被关闭
    f.close()
    print("文件已关闭")

with 语句（推荐）

# 使用 with 语句更简洁
try:
    with open("data.txt", "r") as f:
        content = f.read()
        print(content)
except FileNotFoundError:
    print("文件不存在")
# with 语句会自动关闭文件，不需要 finally

抛出异常

有时候你需要主动抛出异常，比如参数不合法时。

raise 语句

def divide(a, b):
    """安全的除法"""
    if b == 0:
        raise ValueError("除数不能为零")
    return a / b

try:
    result = divide(10, 0)
except ValueError as e:
    print(f"错误: {e}")
    # 输出: 错误: 除数不能为零

自定义异常

class LLMError(Exception):
    """LLM 相关的错误"""
    pass

class ModelNotFoundError(LLMError):
    """模型不存在"""
    pass

class APIError(LLMError):
    """API 调用失败"""
    pass

def call_model(model_name):
    if model_name not in ["qwen2.5:7b", "glm4:9b"]:
        raise ModelNotFoundError(f"模型 {model_name} 不存在")
    # 调用模型的代码...
    pass

try:
    call_model("unknown-model")
except ModelNotFoundError as e:
    print(f"模型错误: {e}")
except APIError as e:
    print(f"API 错误: {e}")
