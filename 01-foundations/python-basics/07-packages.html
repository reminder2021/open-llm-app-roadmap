什么是 pip？

pip 是 Python 的包管理工具，用来安装和管理第三方库。就像手机的应用商店一样，pip 让你可以轻松获取别人写好的代码。

为什么需要第三方库？

不用重复造轮子

别人已经写好的功能，直接用就行。

专业且稳定

经过大量用户验证，比自己写的更可靠。

社区支持

遇到问题可以搜索、提问，有人维护更新。

验证 pip

# 检查 pip 是否已安装
pip3 --version

# 如果显示版本号，说明已安装
# 输出类似: pip 23.x.x from ...

安装包

使用 pip install 命令安装第三方库。

基本安装

# 安装单个包
pip3 install httpx

# 安装指定版本
pip3 install httpx==0.25.0

# 安装最低版本
pip3 install httpx>=0.24.0

# 升级已安装的包
pip3 install --upgrade httpx

卸载包

# 卸载包
pip3 uninstall httpx

# 卸载时不询问确认
pip3 uninstall -y httpx

查看已安装的包

# 列出所有已安装的包
pip3 list

# 查看特定包的信息
pip3 show httpx

# 查看哪些包可以升级
pip3 list --outdated

使用国内镜像（可选）

如果安装速度慢，可以使用国内镜像源：

# 临时使用清华镜像
pip3 install httpx -i https://pypi.tuna.tsinghua.edu.cn/simple

# 永久设置（推荐）
pip3 config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

虚拟环境

虚拟环境是 Python 的"隔离空间"，每个项目可以有自己独立的依赖，互不干扰。

为什么需要虚拟环境？

  • 避免冲突：不同项目可能需要不同版本的同一个库
  • 便于部署：可以精确知道项目依赖了哪些库
  • 保持整洁：不会污染系统的 Python 环境

创建虚拟环境

# 创建虚拟环境（在项目目录下执行）
python3 -m venv .venv

# 激活虚拟环境
# Mac/Linux:
source .venv/bin/activate

# Windows:
.venv\Scripts\activate

# 激活后，命令行前面会显示 (.venv)，表示在虚拟环境中

在虚拟环境中安装包

# 确保已激活虚拟环境
(.venv) $ pip3 install httpx pydantic

# 查看已安装的包
(.venv) $ pip3 list

退出虚拟环境

# 退出虚拟环境
deactivate

删除虚拟环境

# 删除虚拟环境（直接删除 .venv 文件夹即可）
rm -rf .venv

依赖管理

用 requirements.txt 记录项目依赖，方便别人复现你的环境。

导出依赖

# 导出当前环境的所有依赖
pip3 freeze > requirements.txt

# 查看文件内容
cat requirements.txt
# 输出类似:
# httpx==0.25.0
# pydantic==2.5.0
# ...

从文件安装依赖

# 从 requirements.txt 安装所有依赖
pip3 install -r requirements.txt

requirements.txt 示例

# requirements.txt
httpx>=0.24.0
pydantic>=2.0.0
python-dotenv>=1.0.0
fastapi>=0.100.0
uvicorn>=0.23.0

最佳实践

✅ 推荐

  • 每个项目一个虚拟环境
  • 提交 requirements.txt 到 Git
  • 不提交 .venv 文件夹
  • 指定版本范围而非精确版本

❌ 避免

  • 在系统 Python 中安装项目依赖
  • 忘记记录依赖
  • 提交 .venv 到 Git
  • 不指定版本

LLM 应用常用包

以下是 LLM 应用开发中常用的第三方包：

httpx

现代 HTTP 客户端，支持异步请求

import httpx

# 同步请求
response = httpx.get("https://api.example.com")
print(response.json())

# 异步请求
async with httpx.AsyncClient() as client:
    response = await client.get("https://api.example.com")

pydantic

数据校验和设置管理

from pydantic import BaseModel, Field

class User(BaseModel):
    name: str
    age: int = Field(ge=0, le=150)
    email: str

# 自动校验
user = User(name="小明", age=25, email="test@example.com")
print(user.model_dump())

python-dotenv

从 .env 文件加载环境变量

from dotenv import load_dotenv
import os

# 加载 .env 文件
load_dotenv()

# 读取环境变量
api_key = os.getenv("API_KEY")
model_name = os.getenv("MODEL_NAME", "qwen2.5:7b")

fastapi + uvicorn

Web API 框架

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"Hello": "World"}

# 运行: uvicorn main:app --reload

tiktoken

OpenAI 的 Token 计数工具

import tiktoken

encoding = tiktoken.encoding_for_model("gpt-3.5-turbo")
tokens = encoding.encode("Hello, world!")
print(len(tokens))  # 输出: 4

练习 3：使用 pydantic

定义一个 LLM 请求模型：

from pydantic import BaseModel, Field
from typing import List

class Message(BaseModel):
    role: str
    content: str

class LLMRequest(BaseModel):
    model: str = "qwen2.5:7b"
    messages: List[Message]
    temperature: float = Field(default=0.7, ge=0, le=2)
    max_tokens: int = Field(default=512, ge=1, le=4096)

# 测试
request = LLMRequest(
    messages=[
        Message(role="user", content="什么是 RAG？")
    ]
)
print(request.model_dump_json(indent=2))
