你会学到什么？

这个模块不追求 Python 的全部特性，只教你 LLM 应用开发需要的核心能力：

环境搭建

安装 Python、配置编辑器、学会用命令行运行代码。

基本语法

变量、数据类型、条件判断、循环——理解代码的基本结构。

数据结构

列表、字典、JSON——处理 LLM 返回的结构化数据。

函数

把重复的代码封装成函数——写更整洁、可复用的代码。

文件操作

读写文本、JSON、CSV——处理 Prompt 模板和测试数据。

错误处理

用 try/except 捕获异常——让程序在出错时不会崩溃。

包管理

用 pip 安装库、管理依赖——使用 httpx、pydantic 等工具。

综合练习

完成一个小项目——把所学知识串联起来。

学习路径

第 1 周：环境 + 语法 + 数据结构

搭建开发环境，学会 Python 的基本语法和数据处理。这是最基础的部分，需要多练习。

第 2 周：函数 + 文件操作

学会用函数封装代码，掌握文件读写。这些技能在后续 LLM 应用开发中会频繁使用。

第 3 周：错误处理 + 包管理 + 综合练习

学会写出健壮的代码，掌握依赖管理，最后完成一个综合练习项目。

与 LLM 应用开发的关联

你在这里学到的每个知识点，都会在后续的 LLM 应用开发中用到：

  • 字符串操作 → 构造 Prompt 模板
  • 字典和 JSON → 解析模型返回的结构化数据
  • 函数 → 封装模型调用逻辑
  • 文件操作 → 读取知识库文档、保存测试数据
  • 错误处理 → 处理模型调用失败、网络超时
  • 包管理 → 安装 httpx、pydantic、fastapi 等库

学习建议

动手实践

看懂代码不等于会写。每个示例都要自己敲一遍，运行一遍，修改一遍试试。

不怕报错

报错是学习的一部分。学会看错误信息，它会告诉你哪里出了问题。

及时求助

遇到问题不要卡太久。可以搜索错误信息，或者在社区提问。

保持节奏

每天学一点比突击学习更有效。建议每天 1-2 小时，持续 2-3 周。
