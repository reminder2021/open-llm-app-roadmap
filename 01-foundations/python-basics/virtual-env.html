Python 虚拟环境详解

虚拟环境是 Python 开发的基础，掌握它能让你的项目更整洁、更专业。本章详细讲解虚拟环境的创建、使用，以及在 PyCharm 和 VS Code 中的配置方法。

什么是虚拟环境？

虚拟环境是 Python 的一个"隔离空间"，每个项目可以有自己独立的 Python 包，互不干扰。

通俗理解

想象你有两个项目：

  • 项目 A：需要使用 requests 2.28 版本
  • 项目 B：需要使用 requests 2.31 版本

如果没有虚拟环境，这两个项目会冲突。有了虚拟环境，每个项目都有自己的"小房间"，互不影响。

🏠 系统 Python

就像你电脑的"公共客厅"，所有东西都放在一起。

🚪 虚拟环境

就像每个项目的"独立房间"，各自有各自的家具。

为什么需要虚拟环境？

🔄 避免版本冲突

不同项目可以使用不同版本的同一个包。

📦 依赖隔离

项目 A 安装的包不会影响项目 B。

🚀 便于部署

可以精确导出项目依赖，在其他机器上复现环境。

🧹 保持整洁

不会污染系统的 Python 环境。

⚠️ 最佳实践：每个 Python 项目都应该使用虚拟环境！

命令行创建虚拟环境

使用 Python 自带的 venv 模块创建虚拟环境。

步骤 1：创建项目文件夹
# 创建项目文件夹
mkdir my_project
cd my_project
步骤 2：创建虚拟环境
# 创建虚拟环境（venv 是虚拟环境的名字，可以随便取）
python3 -m venv venv

# 查看是否创建成功
ls
# 会看到一个 venv 文件夹
💡 命名建议：虚拟环境文件夹通常命名为 venv 或 .venv。
步骤 3：激活虚拟环境

Mac / Linux

source venv/bin/activate

Windows (CMD)

venv\Scripts\activate.bat

Windows (PowerShell)

venv\Scripts\Activate.ps1

激活后，命令行前面会显示 (venv)，表示你在虚拟环境中：

(venv) user@mac my_project $
步骤 4：验证虚拟环境
# 查看 Python 路径（应该指向 venv 目录）
which python3
# 输出: /Users/xxx/my_project/venv/bin/python3

# 查看 pip 路径
which pip3
# 输出: /Users/xxx/my_project/venv/bin/pip3
步骤 5：退出虚拟环境
# 退出虚拟环境
deactivate

# 退出后，(venv) 前缀消失
user@mac my_project $

完整流程总结

# 1. 创建项目文件夹
mkdir my_project && cd my_project

# 2. 创建虚拟环境
python3 -m venv venv

# 3. 激活虚拟环境
source venv/bin/activate        # Mac/Linux
# venv\Scripts\activate.bat     # Windows CMD

# 4. 现在可以安装包了
pip install requests

# 5. 退出虚拟环境
deactivate

PyCharm 中使用虚拟环境

PyCharm 是很多 Python 开发者使用的 IDE，它对虚拟环境有很好的支持。

方式一：创建项目时创建虚拟环境

步骤 1：新建项目

  1. 打开 PyCharm
  2. 点击 File → New Project（或欢迎界面的 New Project）

步骤 2：配置项目

  1. Location：选择项目保存位置，比如 ~/Projects/my_project
  2. Interpreter type：选择 Virtualenv
  3. Base interpreter：选择你安装的 Python 版本（如 Python 3.11）
  4. Location of new virtual environment：默认即可，通常在项目目录下的 .venv
  5. 勾选 Inherit global site-packages（可选，继承系统已安装的包）
  6. 勾选 Make available to all projects（可选）
📸 PyCharm 新建项目界面
Interpreter type 选择 Virtualenv

步骤 3：点击 Create

PyCharm 会自动创建虚拟环境，等待创建完成即可。

方式二：为已有项目创建虚拟环境

步骤 1：打开设置

  1. 点击 File → Settings（Mac 上是 PyCharm → Preferences）
  2. 找到 Project: 项目名 → Python Interpreter

步骤 2：添加解释器

  1. 点击右上角的 齿轮图标 ⚙️
  2. 选择 Add
  3. 选择 Virtualenv Environment → New environment
  4. Location：默认即可
  5. Base interpreter：选择你的 Python 版本
  6. 点击 OK
📸 PyCharm 添加解释器界面
选择 Virtualenv Environment → New environment

方式三：使用已有的虚拟环境

步骤 1：打开设置

  1. 点击 File → Settings
  2. 找到 Project: 项目名 → Python Interpreter

步骤 2：选择已有解释器

  1. 点击右上角的 齿轮图标 ⚙️
  2. 选择 Add
  3. 选择 Virtualenv Environment → Existing environment
  4. Interpreter：点击 ... 按钮，找到虚拟环境中的 Python
    • Mac/Linux: 项目目录/venv/bin/python3
    • Windows: 项目目录\venv\Scripts\python.exe
  5. 点击 OK
💡 PyCharm 小技巧：
  • PyCharm 底部的 Terminal 会自动激活虚拟环境
  • 在 PyCharm 中安装包：Settings → Python Interpreter → 点击 + 号
  • PyCharm 会自动识别项目目录下的 .venv 文件夹

VS Code 中使用虚拟环境

VS Code 也能很好地支持虚拟环境。

步骤 1：创建虚拟环境

# 在项目目录下创建虚拟环境
python3 -m venv venv

步骤 2：选择 Python 解释器

  1. 按 Cmd + Shift + P（Mac）或 Ctrl + Shift + P（Windows）打开命令面板
  2. 输入 Python: Select Interpreter
  3. 选择 ./venv/bin/python（或 .\venv\Scripts\python）

步骤 3：使用终端

VS Code 的终端会自动激活虚拟环境，你会看到 (venv) 前缀。

💡 VS Code 小技巧：
  • VS Code 会自动识别项目目录下的 .venv 文件夹
  • 如果终端没有自动激活，可以手动运行 source venv/bin/activate
  • 安装 Python 扩展后，VS Code 会提示你选择解释器

在虚拟环境中安装包

激活虚拟环境后，使用 pip install 安装的包只会安装到当前虚拟环境中。

安装单个包
# 确保已激活虚拟环境
(venv) $ pip install requests

# 安装指定版本
(venv) $ pip install requests==2.28.0

# 升级包
(venv) $ pip install --upgrade requests
安装多个包
# 一次安装多个包
(venv) $ pip install requests httpx pydantic
查看已安装的包
# 列出所有已安装的包
(venv) $ pip list

# 查看特定包的信息
(venv) $ pip show requests
卸载包
# 卸载包
(venv) $ pip uninstall requests

依赖管理（requirements.txt）

使用 requirements.txt 记录项目依赖，方便别人复现你的环境。

导出依赖
# 导出当前环境的所有依赖
(venv) $ pip freeze > requirements.txt

# 查看文件内容
(venv) $ cat requirements.txt
# 输出类似:
# httpx==0.25.0
# pydantic==2.5.0
# requests==2.31.0
从文件安装依赖
# 创建新的虚拟环境
python3 -m venv venv
source venv/bin/activate

# 从 requirements.txt 安装所有依赖
(venv) $ pip install -r requirements.txt
💡 最佳实践：
  • 把 requirements.txt 提交到 Git
  • 不要把 venv 文件夹提交到 Git（在 .gitignore 中添加 venv/）
  • 每次安装新包后，更新 requirements.txt

常见问题

问题 1：激活虚拟环境后，python3 还是指向系统 Python
# 检查 Python 路径
which python3

# 如果输出不是 venv 目录下的 Python，说明激活失败
# 解决：重新激活
source venv/bin/activate
问题 2：Windows 上运行 PowerShell 脚本报错
# 错误信息：
# cannot be loaded because running scripts is disabled on this system

# 解决：以管理员身份运行 PowerShell，执行：
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
问题 3：PyCharm 没有自动识别虚拟环境
  1. 打开 Settings → Python Interpreter
  2. 点击齿轮图标 → Add
  3. 选择 Existing environment
  4. 找到 venv/bin/python3（Mac/Linux）或 venv\Scripts\python.exe（Windows）
问题 4：如何删除虚拟环境？
# 直接删除 venv 文件夹即可
rm -rf venv

# 然后可以重新创建
python3 -m venv venv
