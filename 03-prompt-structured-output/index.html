Prompt 与结构化输出

Prompt 不是写一句“请认真回答”。这一阶段学习如何把任务说清楚、让输出稳定、用代码校验结果，并在失败时自动修复。

建议周期：2-3 周产出：结构化信息抽取服务重点：稳定、可校验、可重试

学习目标

会拆任务

把复杂任务拆成分类、抽取、改写、总结、生成等小任务。

会写格式约束

让模型输出 JSON、列表或固定字段，减少自由发挥。

会校验输出

用 Pydantic 判断模型输出是否真的符合要求。

会失败重试

解析失败时保留原始输出，并让模型修复为合法格式。

Prompt 设计

  • 角色：模型应该以什么身份工作。
  • 任务：明确输入是什么、输出是什么。
  • 约束：不能编造、不能输出额外文本、字段必须完整。
  • 示例：给 1-3 个高质量样例比长篇解释更有效。
  • 边界：输入不足时怎么处理，无法判断时怎么返回。

结构化输出

结构化输出的原则是：模型负责生成，程序负责校验。不要默认模型说是 JSON，就一定能被解析。

你是信息抽取助手。
请只输出 JSON，不要输出 Markdown。
字段：
- name: 字符串，无法判断时为空字符串
- skills: 字符串数组
- years: 数字，无法判断时为 0

会话状态管理

  • 短对话可以直接保留最近几轮。
  • 长对话要做摘要或裁剪，避免上下文越来越长。
  • 敏感信息不要无脑放入历史消息。
  • 业务状态最好由程序保存，不要完全依赖模型记忆。

练习任务

任务 1：为信息抽取写 Prompt 模板

把自由文本抽取成固定字段，为后续简历、合同、客服记录等任务打基础。

查看示例 
def build_extract_prompt(text: str) -> str:
    # 用三段式组织 Prompt：角色、规则、输入。
    return f"""你是一个严谨的信息抽取助手。

请从输入文本中抽取信息，并只输出 JSON。
不要输出 Markdown，不要解释过程。

JSON 字段：
- name: 姓名，无法判断时为空字符串
- skills: 技能列表，无法判断时为空数组
- years: 工作年限，无法判断时为 0

输入文本：
{text}
"""

print(build_extract_prompt("张三，Python 工程师，有 3 年后端经验。"))

任务 2：用 Pydantic 校验模型输出

模型输出必须先经过程序校验，才能进入数据库、工具调用或下一步流程。

查看示例 
import json
from pydantic import BaseModel, Field, ValidationError

class ResumeInfo(BaseModel):
    name: str = ""
    skills: list[str] = Field(default_factory=list)
    years: int = Field(default=0, ge=0)

def parse_resume_info(raw_output: str) -> ResumeInfo | None:
    try:
        # 先把字符串解析成 dict，再交给 Pydantic 校验字段类型。
        data = json.loads(raw_output)
        return ResumeInfo(**data)
    except (json.JSONDecodeError, ValidationError) as exc:
        print(f"解析失败: {exc}")
        return None

print(parse_resume_info('{"name": "张三", "skills": ["Python"], "years": 3}'))

任务 3：设计 JSON 修复 Prompt

第一次输出不合法时，不要直接失败，可以把错误信息发回模型要求修复。

查看示例 
def build_repair_prompt(raw_output: str, error: str) -> str:
    # 把原始输出和解析错误都给模型，让它只负责修复格式。
    return f"""下面的内容不是合法 JSON，或不符合字段要求。
请修复为合法 JSON，只输出修复后的 JSON。

字段要求：
- name: string
- skills: array[string]
- years: integer

解析错误：
{error}

原始内容：
{raw_output}
"""

print(build_repair_prompt("姓名：张三，技能：Python", "Expecting value"))

实践项目：简历信息抽取器

输入简历文本，输出姓名、技能、工作年限、项目关键词和风险提示。先不追求完美，重点是形成“Prompt → 模型 → 解析 → 校验 → 重试”的闭环。

查看参考流程代码 
def extract_with_retry(text: str, call_llm) -> dict | None:
    # call_llm 是你封装的模型调用函数，输入 Prompt，返回模型文本。
    prompt = build_extract_prompt(text)
    raw = call_llm(prompt)
    parsed = parse_resume_info(raw)

    if parsed:
        return parsed.model_dump()

    # 第一次失败后，构造修复 Prompt 再试一次。
    repair_prompt = build_repair_prompt(raw, "JSON 解析或字段校验失败")
    repaired = call_llm(repair_prompt)
    parsed = parse_resume_info(repaired)
    return parsed.model_dump() if parsed else None

验收标准

  • 至少准备 20 条简历片段测试。
  • 输出必须能通过 Pydantic 校验。
  • 保存原始输出、解析结果和失败原因。
  • 统计 JSON 解析成功率和重试成功率。
