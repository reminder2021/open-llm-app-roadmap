RAG 知识库问答

RAG 的核心不是“把文档塞给模型”，而是把文档切好、检索准、上下文组织清楚，并让答案可追溯。

建议周期：3-5 周产出：带引用的知识库问答系统重点：召回、引用、防幻觉

本阶段模块

完整流程文档切分检索与重排答案生成练习任务实践项目推荐资料返回主页

完整流程

  1. 加载文档：PDF、Markdown、HTML、Word。
  2. 清洗文本：去页眉页脚、目录、重复空白。
  3. 切分 chunk：保留标题、页码、来源。
  4. 生成 embedding：把 chunk 转成向量。
  5. 写入向量库：保存文本、向量和 metadata。
  6. 问题检索：召回相关 chunk。
  7. Rerank：重新排序，提高上下文质量。
  8. 生成答案：只基于上下文回答，并给出引用。

文档切分

切分太小会丢上下文，切分太大会召回不准。初学建议先从固定长度切分开始，再升级为按标题和段落切分。

查看切分示例 
def chunk_text(text: str, chunk_size: int = 500, overlap: int = 80) -> list[str]:
    # overlap 用来保留相邻片段之间的上下文连续性。
    chunks = []
    start = 0

    while start < len(text):
        end = start + chunk_size
        chunk = text[start:end].strip()
        if chunk:
            chunks.append(chunk)
        start = end - overlap

    return chunks

print(chunk_text("很长的文档内容" * 100, chunk_size=100, overlap=20)[:2])

检索与重排

  • 向量检索适合语义相近的问题。
  • 关键词检索适合专有名词、编号、术语。
  • 混合检索通常比单一路径更稳。
  • Rerank 可以把召回结果重新排序，减少无关上下文进入模型。

答案生成

生成 Prompt 要明确要求：只能基于上下文回答、没有答案就说不知道、必须列出引用来源。

请只基于【参考资料】回答问题。
如果资料中没有答案，请回答“根据当前资料无法判断”。
回答后列出引用来源，格式为 [文件名 - 段落编号]。

练习任务

任务 1：为 chunk 增加 metadata

metadata 是引用、过滤和排查问题的基础。

查看示例 
from dataclasses import dataclass

@dataclass
class Chunk:
    text: str
    source: str
    chunk_id: int

def build_chunks(text: str, source: str) -> list[Chunk]:
    parts = chunk_text(text, chunk_size=300, overlap=50)
    return [
        Chunk(text=part, source=source, chunk_id=index)
        for index, part in enumerate(parts)
    ]

chunks = build_chunks("RAG 是检索增强生成。" * 80, "rag_notes.md")
print(chunks[0])

任务 2：实现一个最小关键词检索

在学习向量库之前，先用关键词检索理解“召回”的含义。

查看示例 
def keyword_search(query: str, chunks: list[Chunk], top_k: int = 3) -> list[Chunk]:
    query_terms = set(query.lower().split())

    def score(chunk: Chunk) -> int:
        text_terms = set(chunk.text.lower().split())
        return len(query_terms & text_terms)

    # 按分数从高到低排序，只返回前 top_k 个。
    ranked = sorted(chunks, key=score, reverse=True)
    return ranked[:top_k]

for item in keyword_search("RAG 检索", chunks):
    print(item.source, item.chunk_id)

任务 3：组织带引用的上下文

把召回结果整理成模型容易理解的上下文。

查看示例 
def format_context(chunks: list[Chunk]) -> str:
    blocks = []
    for chunk in chunks:
        # 给每段资料一个清晰来源，方便模型引用。
        blocks.append(
            f"[{chunk.source} - chunk {chunk.chunk_id}]\n{chunk.text}"
        )
    return "\n\n".join(blocks)

context = format_context(chunks[:2])
print(context)

验收标准

  • 能展示引用文件名和 chunk 编号。
  • 能重新索引文档。
  • 有至少 30 条测试问题。
  • 保存每次问题召回了哪些 chunk。
