LoRA/QLoRA 微调

微调不是让模型记住资料，而是让模型更稳定地完成某类任务、输出某种格式或遵循某种风格。先判断是否真的需要微调，再准备高质量数据。

建议周期：4-8 周产出：领域 LoRA 模型重点：数据、训练、评估

什么时候需要微调

适合

  • 固定输出格式。
  • 领域分类、抽取、改写。
  • 客服话术和写作风格。
  • 工具调用格式稳定化。

不优先

  • 大量知识问答。
  • 实时变化信息。
  • 数据库查询。
  • 文档内容记忆。

数据准备

微调效果主要取决于数据，而不是命令行参数。先准备 500-2000 条高质量样本，比盲目堆数据更有价值。

  • 样本要覆盖正常、边界、失败和拒答场景。
  • 训练集、验证集、测试集要分开。
  • 去掉重复、过长、错误答案和隐私信息。
  • 数据格式要和模型 chat template 匹配。

训练流程

  1. 选择基座模型。
  2. 整理训练数据。
  3. 配置 LoRA 参数。
  4. 运行 SFT 训练。
  5. 在固定测试集上评估。
  6. 部署 adapter 或合并权重。

练习任务

任务 1：构造 instruction 数据

先手写少量高质量样本，理解格式。

查看示例
import json
from pathlib import Path

samples = [
    {
        "instruction": "判断用户意图",
        "input": "我想修改收货地址",
        "output": "change_address",
    },
    {
        "instruction": "判断用户意图",
        "input": "订单什么时候发货？",
        "output": "ask_shipping_status",
    },
]

# JSONL 是微调数据常用格式：一行一个样本。
Path("intent_train.jsonl").write_text(
    "\n".join(json.dumps(s, ensure_ascii=False) for s in samples) + "\n",
    encoding="utf-8",
)

任务 2：划分训练/验证/测试集

不要用同一批数据训练又评估。

查看示例
import random

def split_dataset(items: list[dict], seed: int = 42) -> tuple[list[dict], list[dict], list[dict]]:
    random.seed(seed)
    items = items[:]
    random.shuffle(items)

    n = len(items)
    train = items[: int(n * 0.8)]
    valid = items[int(n * 0.8): int(n * 0.9)]
    test = items[int(n * 0.9):]
    return train, valid, test

任务 3：检查数据质量

训练前先写脚本检查空字段、重复和过长样本。

查看示例
def validate_sample(sample: dict) -> list[str]:
    errors = []
    for key in ["instruction", "input", "output"]:
        if not sample.get(key, "").strip():
            errors.append(f"{key} 为空")

    if len(sample.get("input", "")) > 4000:
        errors.append("input 过长")

    return errors

for index, sample in enumerate(samples):
    errors = validate_sample(sample)
    if errors:
        print(index, errors)

实践项目：客服意图分类微调

选择一个小任务，例如电商客服意图分类。先用 Prompt 做 baseline，再用 LoRA 微调，最后比较两者在测试集上的准确率。

查看评估示例
def accuracy(predictions: list[str], labels: list[str]) -> float:
    # 简单准确率：预测正确数量 / 总数量。
    correct = sum(p == y for p, y in zip(predictions, labels))
    return correct / len(labels) if labels else 0.0

baseline_preds = ["change_address", "ask_shipping_status"]
labels = ["change_address", "ask_shipping_status"]
print("accuracy:", accuracy(baseline_preds, labels))

验收标准

  • 有数据集说明。
  • 有训练前 baseline。
  • 记录训练配置和显存占用。
  • 在同一测试集上对比微调前后效果。

推荐资料

  • Hugging Face PEFT：学习 LoRA、QLoRA 等参数高效微调。
  • Hugging Face TRL：学习 SFTTrainer、偏好优化和训练流程。
  • TRL + PEFT 集成：学习如何在 TRL 训练器中使用 LoRA/QLoRA。
  • Transformers Training：理解基础训练配置和 Trainer。
