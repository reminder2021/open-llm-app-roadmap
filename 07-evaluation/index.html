评估体系

LLM 应用不能只靠“感觉还行”。你需要固定测试集、明确指标、保存实验结果，才能知道 Prompt、RAG、工具调用或微调是否真的变好。

建议周期：2-4 周，并贯穿全程产出：评估脚本与测试集重点：可复现对比

本阶段模块

测试集指标流程练习任务实践项目推荐资料返回主页

构建测试集

  • 从真实用户问题、业务文档和失败案例中抽样。
  • 覆盖简单问题、复杂问题、边界问题、无答案问题和恶意输入。
  • 每条样本要有期望答案、评分标准和来源。
  • 测试集固定后不要频繁修改，否则无法比较版本。

核心指标

结构化输出

JSON 合法率、字段准确率、重试成功率。

RAG

召回命中率、引用正确率、答案忠实度。

工具调用

工具选择准确率、参数正确率、执行成功率。

工程指标

延迟、失败率、并发能力、成本。

评估流程

  1. 固定模型、Prompt、检索参数和工具版本。
  2. 运行测试集，保存输入、中间步骤和输出。
  3. 自动计算可量化指标。
  4. 人工复核主观质量和失败案例。
  5. 记录实验版本，方便回滚和对比。

练习任务

任务 1：设计测试集格式

先用 JSONL 保存测试样本，方便逐行读取。

查看示例
import json
from pathlib import Path

cases = [
    {
        "id": "rag_001",
        "question": "RAG 的核心流程是什么？",
        "expected_keywords": ["检索", "上下文", "生成"],
        "source": "rag_notes.md",
    }
]

Path("eval_cases.jsonl").write_text(
    "\n".join(json.dumps(c, ensure_ascii=False) for c in cases) + "\n",
    encoding="utf-8",
)

任务 2：计算关键词命中率

这是一个非常简单的自动评分方法，适合入门。

查看示例
def keyword_hit_rate(answer: str, expected_keywords: list[str]) -> float:
    if not expected_keywords:
        return 1.0
    hits = sum(1 for keyword in expected_keywords if keyword in answer)
    return hits / len(expected_keywords)

answer = "RAG 先检索相关资料，再把上下文交给模型生成答案。"
print(keyword_hit_rate(answer, ["检索", "上下文", "生成"]))

任务 3：保存评估结果

每次实验都要能追溯模型、Prompt 和参数。

查看示例
import csv

def save_eval_result(file_path: str, rows: list[dict]) -> None:
    fieldnames = ["case_id", "model", "score", "latency_ms", "answer"]
    with open(file_path, "w", encoding="utf-8", newline="") as file:
        writer = csv.DictWriter(file, fieldnames=fieldnames)
        writer.writeheader()
        writer.writerows(rows)

save_eval_result("eval_results.csv", [
    {"case_id": "rag_001", "model": "local-model", "score": 1.0, "latency_ms": 1200, "answer": "RAG 先检索..."}
])

实践项目：RAG 评估脚本

为知识库问答系统建立至少 100 条问题，比较不同 chunk 参数、Embedding、Reranker 和模型。

验收标准

  • 测试集和评估结果可提交到仓库。
  • 每次实验有版本号和参数记录。
  • 输出总分、失败案例和平均延迟。
  • 至少做 3 组参数对比。

推荐资料

  • Hugging Face Evaluate：学习常见评估指标和评估流程。
  • LlamaIndex Evaluation：学习 RAG 和 LLM 应用评估。
  • Ragas 文档：学习 RAG 评估指标，如 faithfulness、answer relevancy、context precision。
  • LangSmith 文档：学习实验追踪、调试和评估。
