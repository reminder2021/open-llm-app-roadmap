项目二

个人知识库问答系统

目标是掌握 RAG 全链路：文档解析、切分、索引、检索、引用、评估。

  • 支持上传 Markdown/PDF。
  • 支持索引和重新索引。
  • 答案带引用来源。
  • 有测试集和评估脚本。

项目三

带工具调用的业务助手

目标是掌握 Tool Calling、Agent 状态、权限控制和 LangGraph 流程编排。

  • 至少 4 个工具：知识库、计算器、API 查询、文件处理。
  • 工具参数有 Schema 校验。
  • 危险操作需要人工确认。
  • 记录每一步工具调用。

前端展示（可选但推荐）

虽然这个路线主要聚焦后端，但一个完整的 LLM 应用通常需要前端界面。以下是几种适合 LLM 应用的前端方案。

方案一：Gradio（最快上手）

  • 适合场景：快速原型、Demo 展示、内部工具
  • 优点：几行代码生成界面、支持流式输出、可直接部署到 Hugging Face
  • 缺点：自定义程度有限、不适合复杂交互

方案二：Streamlit（数据应用）

  • 适合场景：数据可视化、仪表板、内部工具
  • 优点：Python 原生、组件丰富、部署简单
  • 缺点：性能一般、不适合高并发

方案三：React + Next.js（生产级）

  • 适合场景：正式产品、需要定制化 UI
  • 优点：完全可控、性能好、生态丰富
  • 缺点：需要前端开发能力、开发周期长

方案四：静态 HTML + JS（轻量）

  • 适合场景：简单聊天界面、学习项目
  • 优点：无框架依赖、部署简单、易于理解
  • 缺点：功能有限、需要手动处理状态
选择建议：
  • 学习阶段优先用 Gradio 或 Streamlit，快速验证想法。
  • 作品集项目建议至少有一个用 React/Next.js，展示全栈能力。
  • 聊天界面一定要支持流式输出，用户体验差别很大。
查看 Gradio 聊天界面示例 
import gradio as gr
import httpx

async def chat_with_llm(message: str, history: list):
    """与 LLM 对话的生成器函数"""
    # 构建消息历史
    messages = []
    for user_msg, bot_msg in history:
        messages.append({"role": "user", "content": user_msg})
        messages.append({"role": "assistant", "content": bot_msg})
    messages.append({"role": "user", "content": message})

    # 调用本地模型服务（流式）
    async with httpx.AsyncClient(timeout=60) as client:
        async with client.stream(
            "POST",
            "http://localhost:8000/v1/chat/completions",
            json={
                "model": "local-model",
                "messages": messages,
                "stream": True
            }
        ) as response:
            partial = ""
            async for line in response.aiter_lines():
                if line.startswith("data: "):
                    data = line[6:]
                    if data == "[DONE]":
                        break
                    try:
                        chunk = json.loads(data)
                        content = chunk["choices"][0]["delta"].get("content", "")
                        partial += content
                        yield partial
                    except:
                        continue

# 创建 Gradio 界面
demo = gr.ChatInterface(
    fn=chat_with_llm,
    title="本地 LLM 聊天助手",
    description="基于开源模型的对话系统",
    examples=["什么是 RAG？", "解释一下 LangChain"],
    retry_btn="重新生成",
    undo_btn="撤销",
    clear_btn="清空对话"
)

if __name__ == "__main__":
    demo.launch(server_port=7860)
查看 Streamlit 聊天界面示例 
import streamlit as st
import httpx

st.title("本地 LLM 聊天助手")
st.caption("基于开源模型的对话系统")

# 初始化消息历史
if "messages" not in st.session_state:
    st.session_state.messages = []

# 显示历史消息
for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])

# 用户输入
if prompt := st.chat_input("输入消息..."):
    # 显示用户消息
    st.session_state.messages.append({"role": "user", "content": prompt})
    with st.chat_message("user"):
        st.markdown(prompt)

    # 调用模型并流式显示
    with st.chat_message("assistant"):
        message_placeholder = st.empty()
        full_response = ""

        # 调用本地模型服务
        with httpx.Client(timeout=60) as client:
            with client.stream(
                "POST",
                "http://localhost:8000/v1/chat/completions",
                json={
                    "model": "local-model",
                    "messages": [
                        {"role": m["role"], "content": m["content"]}
                        for m in st.session_state.messages
                    ],
                    "stream": True
                }
            ) as response:
                for line in response.iter_lines():
                    if line.startswith("data: "):
                        data = line[6:]
                        if data == "[DONE]":
                            break
                        try:
                            chunk = httpx.Response(200, content=data).json()
                            content = chunk["choices"][0]["delta"].get("content", "")
                            full_response += content
                            message_placeholder.markdown(full_response + "▌")
                        except:
                            continue

        message_placeholder.markdown(full_response)
        st.session_state.messages.append({"role": "assistant", "content": full_response})

# 侧边栏：清除历史
with st.sidebar:
    if st.button("清除对话历史"):
        st.session_state.messages = []
        st.rerun()
查看简单 HTML 聊天界面示例 
<!DOCTYPE html>
<html lang="zh">
<head>
    <meta charset="UTF-8">
    <title>LLM 聊天助手</title>
    <style>
        body { font-family: sans-serif; max-width: 800px; margin: 0 auto; padding: 20px; }
        #chat-box { height: 400px; overflow-y: auto; border: 1px solid #ccc; padding: 10px; margin-bottom: 10px; }
        .message { margin: 10px 0; padding: 8px 12px; border-radius: 8px; }
        .user { background: #007bff; color: white; text-align: right; }
        .bot { background: #f1f1f1; }
        #input-area { display: flex; gap: 10px; }
        #user-input { flex: 1; padding: 10px; }
        button { padding: 10px 20px; }
    </style>
</head>
<body>
    <h1>LLM 聊天助手</h1>
    <div id="chat-box"></div>
    <div id="input-area">
        <input type="text" id="user-input" placeholder="输入消息...">
        <button onclick="sendMessage()">发送</button>
    </div>

    <script>
        const chatBox = document.getElementById('chat-box');
        const userInput = document.getElementById('user-input');

        async function sendMessage() {
            const message = userInput.value.trim();
            if (!message) return;

            // 显示用户消息
            appendMessage('user', message);
            userInput.value = '';

            // 调用后端 API
            try {
                const response = await fetch('/v1/chat/completions', {
                    method: 'POST',
                    headers: {'Content-Type': 'application/json'},
                    body: JSON.stringify({
                        model: 'local-model',
                        messages: [{role: 'user', content: message}],
                        stream: true
                    })
                });

                const reader = response.body.getReader();
                const decoder = new TextDecoder();
                let botMessage = '';
                const botDiv = appendMessage('bot', '');

                while (true) {
                    const {done, value} = await reader.read();
                    if (done) break;

                    const chunk = decoder.decode(value);
                    const lines = chunk.split('\n');

                    for (const line of lines) {
                        if (line.startsWith('data: ')) {
                            const data = line.slice(6);
                            if (data === '[DONE]') break;
                            try {
                                const json = JSON.parse(data);
                                const content = json.choices[0].delta.content || '';
                                botMessage += content;
                                botDiv.textContent = botMessage;
                            } catch (e) {}
                        }
                    }
                }
            } catch (error) {
                appendMessage('bot', '错误: ' + error.message);
            }
        }

        function appendMessage(role, content) {
            const div = document.createElement('div');
            div.className = 'message ' + role;
            div.textContent = content;
            chatBox.appendChild(div);
            chatBox.scrollTop = chatBox.scrollHeight;
            return div;
        }

        userInput.addEventListener('keypress', (e) => {
            if (e.key === 'Enter') sendMessage();
        });
    </script>
</body>
</html>
