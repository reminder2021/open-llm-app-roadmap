如何提交你的作品

我们推荐以下方式展示你的学习成果：

方式一：GitHub Discussions（推荐）

  • 在 📣 Show and Tell 频道发帖
  • 附上项目截图或 GIF
  • 附上 GitHub 仓库链接
  • 分享你的学习心得和踩坑记录

方式二：提交 Pull Request

  • Fork 本仓库
  • 在 showcase/projects/ 目录下创建你的项目页面
  • 提交 PR，我们会审核后合并
  • 适合想要详细展示的项目
提示：无论选择哪种方式，请确保你的项目：
  • 有清晰的 README 说明如何运行
  • 代码有基本的注释
  • 不包含敏感信息（API Key、密码等）
