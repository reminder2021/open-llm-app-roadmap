项目概述

Langchain-Chatchat 是一个基于 ChatGLM 等大语言模型与 Langchain 框架实现的开源 RAG 与 Agent 应用项目，支持本地知识库问答和多种工具调用。

核心价值

  • 完整的 RAG 实现：文档加载、切分、向量化、检索、生成
  • 强大的 Agent 能力：工具调用、MCP 协议支持
  • 生产级架构：FastAPI + Streamlit + 多种向量数据库
  • 易于扩展：模块化设计，支持多种模型和工具

适用场景

  • 企业知识库问答系统
  • 智能助手与 Agent 应用
  • 文档分析与检索系统
  • 研究辅助工具
GitHub Stars: 20K+ 活跃维护 中文友好

    # 4. 流式输出结果
    async for item in agent_executor.invoke({"input": query}):
        yield OpenAIChatOutput(content=item.text, tool_calls=item.tool_calls)

实现细节

RAG 完整流程

  1. 文档加载: 支持 PDF、Word、Markdown、HTML 等格式
  2. 文本切分: 使用 ChineseRecursiveTextSplitter 等分词器
  3. 向量化: 调用 Embedding 模型生成向量
  4. 存储索引: 写入向量数据库（FAISS、Milvus 等）
  5. 检索匹配: 根据问题检索相关文档片段
  6. 答案生成: 使用 LLM 基于检索结果生成答案

Agent 工具调用流程

用户输入 → 意图识别 → 工具选择 → 参数提取 → 工具执行 → 结果整合 → 答案生成

具体实现：
1. 用户输入问题
2. LLM 分析是否需要工具
3. 选择合适的工具（如知识库搜索、网络搜索）
4. 提取工具参数
5. 执行工具获取结果
6. 整合工具结果和上下文
7. 生成最终答案

# custom_tool.py
from chatchat.server.agent.tools_factory.tools_registry import regist_tool
from pydantic import BaseModel, Field

class WeatherInput(BaseModel):
    city: str = Field(description="城市名称")
    unit: str = Field(default="celsius", description="温度单位")

@regist_tool(
    title="天气查询",
    description="查询指定城市的天气信息",
    args_schema=WeatherInput,
    return_direct=True
)
def get_weather(city: str, unit: str = "celsius") -> str:
    """查询天气信息"""
    # 实现天气查询逻辑
    import requests
    api_key = "your_api_key"
    url = f"https://api.weather.com/v1?city={city}&unit={unit}&key={api_key}"
    response = requests.get(url)
    data = response.json()
    
    return f"{city}天气：{data['weather']}，温度：{data['temperature']}°{unit[0].upper()}"

示例 2：自定义知识库服务

# custom_kb_service.py
from chatchat.server.knowledge_base.kb_service.base import KBService, SupportedVSType
from langchain.docstore.document import Document
from typing import List, Tuple

class CustomKBService(KBService):
    """自定义知识库服务实现"""
    
    def vs_type(self) -> str:
        return "custom"
    
    def do_init(self):
        """初始化自定义向量库"""
        self.vector_store = self._create_vector_store()
    
    def do_search(self, query: str, top_k: int, score_threshold: float) -> List[Tuple[Document, float]]:
        """实现搜索逻辑"""
        docs = self.vector_store.similarity_search_with_score(query, k=top_k)
        return [(doc, score) for doc, score in docs if score <= score_threshold]
    
    def do_add_doc(self, docs: List[Document], **kwargs) -> List[Dict]:
        """实现文档添加逻辑"""
        ids = self.vector_store.add_documents(docs)
        return [{"id": id, "metadata": doc.metadata} for id, doc in zip(ids, docs)]

示例 3：流式对话实现

# stream_chat.py
from fastapi import FastAPI
from sse_starlette.sse import EventSourceResponse
from chatchat.server.chat.chat import chat

app = FastAPI()

@app.post("/chat/stream")
async def stream_chat(query: str, conversation_id: str):
    """流式对话接口"""
    async def event_generator():
        async for chunk in chat(
            query=query,
            conversation_id=conversation_id,
            stream=True
        ):
            yield {
                "event": "message",
                "data": chunk.model_dump_json()
            }
    
    return EventSourceResponse(event_generator())
